# Area 11 app-migrations, part 1: file inventory

Scope command: `python3 /home/blackbox/kurobayomi/plans/_tools/areas.py files 11-app-migrations 1` prints 54 files (53 under `app/src/main/java/mihon/core/migration/` plus the test). All 54 paths appear below verbatim. LOC is the value printed by the scope command.

Summary: 7 framework files, 44 migration classes (one per file), 2 helper files (`MigrationUtils.kt`, `Migrations.kt`), 1 test file. Dispositions: 3 always-run steps PORT as scheduler set-up, 1 step PORTs as a reusable helper, 29 steps become pure normaliser rules (NORM, priority P2), 11 steps are dropped (DROP, P3) and 1 step (`MigrateSecureScreenMigration.kt`) is split into NORM and DROP.

Decision vocabulary: **Port** = same behaviour in Rust, **Rewrite** = same contract, Rust-idiomatic implementation, **Replace** = Linux-native mechanism, **Drop** = not carried over, reason given. "NORM" = pure conversion function in `kuro-prefs::legacy` that runs only when an old backup is imported (see `p1-topic-legacy-normaliser.md`).

Priorities: P0 framework needed to start the app, P1 scheduler and categories, P2 legacy normaliser rules, P3 dropped steps.
