- **Port**: behavior is ported 1:1 to Rust (logic, constants, ordering).
- **Rewrite**: behavior is kept, the Kotlin structure is replaced (state machine, concurrency model).

- **Drop**: removed; reason and user impact stated.

- `kuro-chapters` = pure logic crate (no GTK, no tokio), new.

- `kuro-ui` = GTK4 widgets, the current `src/` mockup evolves into this.
