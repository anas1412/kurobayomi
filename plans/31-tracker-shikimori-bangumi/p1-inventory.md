# Area 31-tracker-shikimori-bangumi, part 1: inventory

Scope: Shikimori and Bangumi tracker implementations in Aniyomi. Every path is repo-relative to `/home/blackbox/aniyomi-src`. The scope command `areas.py files 31-tracker-shikimori-bangumi 1` prints 17 files and 1,501 LOC in total (Bangumi 754, Shikimori 747). No file in scope is a test, a composable or an Activity. No file in scope renders UI, so there is no `p1-ui-parity.md`.

Legend for the decision column:
- **Rewrite**: the logic is reproduced in Rust with the same observable behaviour, but the code is not a line-by-line port.
- **Port**: plain data (DTO or constant) reproduced field for field.
- **Replace-with-crate**: an Android or Kotlin mechanism replaced by a named crate (see p1-rust-design.md section 9).
- **Drop**: none in this area. Every observable behaviour is kept, including the observed defects, unless p1-behavior.md section 8 marks a fix as a proposal.

Task ids refer to p1-tasks.md. Shared task numbering: `T-31a-001` to `T-31a-049`.
