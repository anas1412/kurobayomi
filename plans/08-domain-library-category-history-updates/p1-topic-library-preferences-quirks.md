# Area 08 — Topic: quirks, upstream defects and decisions

Each row: what the Kotlin does (OBSERVED, with source), the user-visible effect, and the Kurobayomi decision. "Keep" = reproduce for compatibility (usually because a restored backup or an existing preference would otherwise change meaning). "Fix" = deliberately deviate. Decisions are enforced by tests in `p1-edge-cases-and-tests.md`.

| Q1 | `displayEpisodeByNameOrNumber()` and `displayChapterByNameOrNumber()` both use key `default_chapter_display_by_name_or_number`; `sortEpisodeByAscendingOrDescending()` and `sortChapterByAscendingOrDescending()` both use `default_chapter_sort_by_ascending_or_descending` (`domain/src/main/java/tachiyomi/domain/library/service/LibraryPreferences.kt:205-223`) | Setting the default chapter display/direction also changes the default episode display/direction and vice versa.
