Port-decision vocabulary:
- **Port**: behaviour reproduced in Rust with the same semantics (same constants, same ordering, same error paths).
- **Rewrite**: same job and same observable behaviour, Rust-idiomatic shape (no Kotlin class structure kept).
- **Replace-with-crate**: the Android mechanism is replaced by a named crate or std item.
- **Drop**: not carried over. Reason and user loss are stated in the row and in `p1-behavior.md` section 15.

Target crates (see `p1-rust-design.md`):
- `kuro-extensions` (new, no GTK): model, index, repo store, trust, loader, installer, state reducer, views.

- `kurobayomi` (GTK UI): consumes `kuro-extensions` through an event channel.
