# Area 12-network-stack, part 1: inventory

Scope command: `python3 plans/_tools/areas.py files 12-network-stack 1` prints 21 files, 1572 lines. Every row below is one of those files. All paths are repo-relative to `/home/blackbox/aniyomi-src`.

Decision legend: **Port** = same logic in Rust; **Rewrite** = same behaviour, different structure; **Replace-with-crate** = a Rust crate or a Linux API does the work; **Drop** = not carried over (reason and loss stated).

Target crates: `kuro-net` is the new platform-independent network crate (no `cfg(target_os)`); `kuro-platform` holds `WebViewHost` and the Linux WebKitGTK implementation (rule 1 of `plans/addenda/requirements-cross-platform.md`); `kuro-core` holds small helpers shared by many areas; `kuro-ui` stands for the GTK code in the existing `src/` tree (`src/ui.rs`, `src/settings.rs`). Design is in `p1-rust-design.md`.
