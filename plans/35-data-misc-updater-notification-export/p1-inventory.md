# Area 35 - Notifications, app updater, library export, misc data services (part 1 of 1): inventory

Scope: the 11 files printed by `areas.py files 35-data-misc-updater-notification-export 1`. Every path below is repo-relative to `/home/blackbox/aniyomi-src`. LOC is the line count from that command.

Port decision vocabulary:
- **Port**: behaviour is reproduced 1:1 in Rust.
- **Rewrite**: the Kotlin design is discarded, the observable behaviour is kept (or corrected where marked).
- **Replace-with-crate / Replace-with-platform**: the Android API is replaced by a named Linux or Rust mechanism.
- **Drop**: the feature has no Linux meaning; the user-visible loss is stated.

Target crates follow `addenda/requirements-cross-platform.md`: OS access goes through the `kuro-platform` traits (`Notifier`, `Opener`, `Paths`, `NetworkStatus`). Application code lives in the `kurobayomi` crate under `src/notify/`, `src/update/`, `src/export/`.

Priorities follow the rules: P0 = needed for daily reading/watching; P1 = parity most users rely on; P2 = long tail; P3 = Android-only, drop or replacement decision stated.
