Port decision vocabulary:
- **Port**: same behaviour, rewritten in Rust with the same rules.
- **Rewrite**: same user-visible behaviour, different mechanism (for example WorkManager becomes a tokio task).
- **Replace-with-crate**: an Android/Kotlin library call is replaced by a named crate or GIO API.
- **Drop**: no Linux equivalent is needed. The reason and the lost user value are in the behaviour document.

Target module names are proposals. The crate layout follows `plans/01-foundation-app-bootstrap/p1-rust-design.md` section 1: `kuro-track` for logic, `kuro-platform` for OS traits, `kuro-db` and `kuro-net` from areas 05 and 12, and the GTK crate `kurobayomi` (`src/`) for UI.
