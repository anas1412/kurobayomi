Port decision legend (used in the table below):
- **Port**: behavior is reproduced 1:1 in Rust (same constants, same ordering, same edge cases).
- **Rewrite**: behavior is kept, the Kotlin structure is replaced (Voyager ScreenModel, Compose state, coroutine dispatch).
- **Replace-with-crate**: an Android/Kotlin dependency is swapped for a named Rust or Linux component.
- **Drop**: removed, with the reason and the user impact stated.

Short names used in the table:
- `kuro-core` = pure logic + DB + services crate, no GTK (new in Kurobayomi).
- `kuro-ui` = GTK4 widgets (the current `src/` mockup evolves into this).
- Module paths are defined in `p2-rust-design.md`.
