## Per-file notes that change the decision

- `ImageUtil.kt` is the largest file and the only one with four separate responsibilities (format sniffing, codec wrappers, page operations, background colour). The Rust module is split along those lines; see `p1-topic-image-processing.md`.
- `DiskUtil.kt` mixes three concerns with different fates: filename rules (Port, and extended for NTFS), free-space queries (Replace), and Android media scanning and SD-card enumeration (Drop).
- `EpubReader.kt` depends on jsoup's lenient HTML parser (it parses OPF and container XML as HTML). The Rust port must use an HTML5 parser, not a strict XML parser, so that malformed packages keep loading. Details: `p1-topic-archive-cbz-epub.md`.
- `TorrentServerUtils.kt` and `TorrentServerApi.kt` depend on an Android AAR (`xyz.secozzi.torrserver.TorrServer`, gomobile) that is not in this repository. The Linux replacement is a supervised child process (see `p1-topic-torrserver-lifecycle.md`).
- `TorrentPreferences.kt` contains the default tracker list (26 lines once spaces are removed, 967 characters). The list is reproduced in `p1-data-and-config.md`.
