## 0. Conventions

### 0.1 OBSERVED: the store (shortened, full text in `catalogs/preferences-01.md` section 1)

- Flat Android `SharedPreferences`, three logical stores by key prefix (`core/common/src/main/java/tachiyomi/core/common/preference/Preference.kt:28-48`):
  - normal: no prefix. Included in backups.
  - app-state: prefix `__APP_STATE_` (`Preference.appStateKey`). Never in backups.
  - private: prefix `__PRIVATE_` (`Preference.privateKey`). In backups only with the "private settings" option.
- `getEnum` stores `Enum.name`; an unknown name returns the default.
- Migrations that touch keys in this chunk are in `app/src/main/java/mihon/core/migration/migrations/`: `AddAllLangMigration.kt` (v70), `MigrateSecureScreenMigration.kt` (v75), `RemoveReaderTapMigration.kt` (v77), `RelativeTimestampMigration.kt` (v106), `NoAppStateMigration.kt` (v113), `PrivatePreferenceMigration.kt` (v116), `PermaTrustExtensionsMigration.kt` (v117), `NavigationOptionsMigration.kt` (v120).

### 0.2 Proposal: Rust settings layout used in the "Rust field" column

- `settings.json` under `$XDG_CONFIG_HOME/kurobayomi/` (normal store), one `Settings` struct, `#[serde(default)]` on every field, atomic write (tmp file + rename). Field spelled `section.field` is `Settings.section.field`.
- `state.json` under `$XDG_STATE_HOME/kurobayomi/` for app-state values (`state.*`), never exported.
- Secrets in the freedesktop Secret Service via `oo7` (KWallet implements it), never in the JSON files.
- Enums use `#[serde(rename = "<Kotlin constant name>")]` per variant so Aniyomi backup values import unchanged.
- Aniyomi backup import (area:22-backup-restore) reads the legacy key from the "key" column; Kurobayomi's export writes the same keys for the keys marked keep.
