### `landscape_zoom`

### `ignore_gif` and `ignore_jpeg`
- OBSERVED. Both belong to the "data saver" feature that rewrites page image URLs through a third-party compression service before the reader or the downloader fetches them (`aniyomi.util.DataSaver`). The two flags are read once when a `DataSaver` object is created: per `HttpPageLoader` instance (`app/src/main/java/eu/kanade/tachiyomi/ui/reader/loader/HttpPageLoader.kt:51`) and per download job (`app/src/main/java/eu/kanade/tachiyomi/data/download/manga/MangaDownloader.kt:374-378`, which is skipped when `data_saver_downloader` is false). Matching is a case-insensitive substring test on the whole image URL, jpeg first: URL contains `.jpeg` or `.jpg` returns the original URL when `ignore_jpeg` is true else the compressed URL; otherwise URL contains `.gif` returns the original URL when `ignore_gif` is true else the compressed URL; every other URL is always compressed. Bandwidth Hero additionally requires `data_saver_server` non-blank and a URL that does not already contain the server string. Rewrite formats: Bandwidth Hero `"$server/?jpg=$format&l=$quality&bw=$colorBW&url=${URLEncoder.encode(url, "utf-8")}"` with `format` and `colorBW` rendered as `"1"`/`"0"`; wsrv.nl `"https://wsrv.nl/?url=$imageUrl"` followed by `&q=$quality&n=-1` (for `.webp`/`.gif` sources when not converting to JPEG), `&output=jpg&q=$quality&n=-1` (for `.webp`/`.gif` sources when converting), `&output=jpg&q=$quality` (other sources when converting) or `&output=webp&q=$quality` (other sources otherwise); resmush.it performs `GET http://api.resmush.it/ws.php?img=$imageUrl&qlty=$quality` and returns the text between `"dest":"` and `",` of the body (DataSaver.kt:63-82, 99-132, 143-165). A source id in `data_saver_excluded` bypasses the whole thing (DataSaver.kt:48-51).
- UI. Settings > Advanced > Data Saver: "Ignore Jpeg Images" and "Ignore Gif Animations" (`AYMR.strings.data_saver_ignore_jpeg`, `data_saver_ignore_gif`), both enabled only when the data-saver mode is not `NONE` (SettingsAdvancedScreen.kt:509-517). Enum of the mode (`data_saver`, owned by another chunk): `NONE`, `BANDWIDTH_HERO`, `WSRV_NL`, `RESMUSH_IT`.
- Proposal (P2; area:43-reader-core, area:34-images-covers-cache). Keep, as a URL-rewriting step in the page-image fetcher with the exact rewrite formats above and these defaults (`ignore_jpeg = false`, `ignore_gif = true`). Percent-encode with `percent-encoding`'s `NON_ALPHANUMERIC` minus the characters `URLEncoder` leaves alone (`.`, `-`, `*`, `_`; space becomes `+`). The user loses nothing by deferring: when `data_saver.mode = none` these two flags have no effect.

### `last_app_check`
- OBSERVED. Throttle for the self-update check: `GetApplicationRelease.await` skips the network call when `!forceCheck && now < lastChecked + 3 days` and returns `Result.NoNewUpdate`; the stored time is only updated after a successful `service.latest(arguments)` call (GetApplicationRelease.kt:19-33). The check runs from `MainActivity.CheckForUpdates()` on start when the build flag `updaterEnabled` is true and from About > "Check for updates" with `forceCheck = true` (toasts "No new updates available" when none). Release lookup: `GET https://api.github.com/repos/{aniyomiorg/aniyomi | aniyomiorg/aniyomi-preview}/releases/latest`. Version compare for release builds: strip `[^\d.]` from both strings, split on `.`, map each part with `toInt()`, and return true as soon as any component of the new version is greater than the component of the old version at the same index (`GetApplicationRelease.kt:48-76`). Defects: it is not lexicographic, so new `1.0.5` against old `1.2.0` returns true because `5 > 0` at index 2; a new version with fewer components than the old one throws `IndexOutOfBoundsException`; a non-numeric component throws `NumberFormatException`. Preview builds compare `newVersion.toInt() > commitCount`.
- Decision, Drop. Reason: a Linux package is updated by the package manager (AUR/pacman, Flatpak) or `cargo install`, and a self-updating binary would bypass it. What the user loses: an in-app "new version" prompt. Replacement: AUR/Flatpak update notifications through the desktop's software centre. If a prompt is wanted later it is a P3 item: one `GET https://api.github.com/repos/<owner>/kurobayomi/releases/latest` at most every 3 days, using a proper semver comparison instead of the index-wise rule.

### `jellyfin`
- OBSERVED. Not a preference key. It is the literal prefix of the seed string that reproduces the source id of the Jellyfin ANIME extension so the Jellyfin tracker can look up the user's credentials. `JellyfinInterceptor.getId(suffix)` (JellyfinInterceptor.kt:42-47): `key = "jellyfin" + (if (suffix == 1) "" else " ($suffix)") + "/all/$JELLYFIN_VERSION_ID"` with `JELLYFIN_VERSION_ID = 1`; `id = first 8 bytes of MD5(key.toByteArray()) assembled big-endian into a Long, and Long.MAX_VALUE`. `getApiKey(userId)` loops `suffix in 1..MAX_JELLYFIN_SOURCES (10)`, takes that source's own `SharedPreferences`, skips it when `user_id` is empty, and returns its `api_key` when `user_id == userId`. The interceptor: always replaces `User-Agent` with `"Aniyomi v${BuildConfig.VERSION_NAME} (${BuildConfig.APPLICATION_ID})"`; if the request already has the query parameter `api_key` it proceeds unchanged; else `userId = query "userId" ?: pathSegments[1]`, `apiKey = cache[userId] ?: getApiKey(userId)`, and when none is found it throws `IOException("Please log in through the extension")`; otherwise it appends `api_key` to the URL. The tracker is registered with `JELLYFIN = 102L` and accepts the extension class `eu.kanade.tachiyomi.animeextension.all.jellyfin.Jellyfin` (`Jellyfin.kt:86`).
- Proposal (area:33-tracker-enhanced-kavita-komga-suwayomi-jellyfin, area:20-extension-strategy-redesign). The Rust app cannot run the Android extension, so the Jellyfin source/tracker pair becomes one native module holding `server_url`, `user_id`, `api_key` in the OS keyring (Secret Service, `oo7` crate); no id-hash lookup is needed. For backup/restore compatibility keep this function so ids of imported Jellyfin library entries match:
  ```rust
  fn jellyfin_source_id(suffix: u32) -> i64 {
      let key = format!("jellyfin{}/all/1", if suffix == 1 { String::new() } else { format!(" ({suffix})") });
      let d = md5::compute(key.as_bytes()).0;
      (u64::from_be_bytes(d[..8].try_into().unwrap()) & (i64::MAX as u64)) as i64
  }
  ```
  evaluated for `suffix` 1 to 10.
