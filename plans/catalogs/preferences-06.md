## 0. Storage model (applies to every row)

### 0.1 OBSERVED: how Aniyomi stores preferences

- `PreferenceStore` (`core/common/src/main/java/tachiyomi/core/common/preference/PreferenceStore.kt`) offers `getString`, `getLong`, `getInt`, `getFloat`, `getBoolean`, `getStringSet`, `getObject`.
  - Default for each primitive when the caller omits it: `""`, `0`, `0`, `0f`, `false`, `emptySet()`. Example: `getInt("pref_player_filter_brightness")` has default 0.
- The Android implementation is `AndroidPreference` (`core/common/src/main/java/tachiyomi/core/common/preference/AndroidPreference.kt`), backed by the app's default `SharedPreferences` (`PreferenceManager.getDefaultSharedPreferences`).
  - A stored value of the wrong primitive type throws `ClassCastException`. `get()` then logs `Invalid value for $key; deleting`, deletes the key and returns the default (`AndroidPreference.kt:32-40`).
- Enums use `getEnum` (`PreferenceStore.kt:27-43`).
  - Serialised as the string `enum.name` (for example `"Seek"`, `"BLACK"`).
  - An unknown name deserialises to the default (`catch IllegalArgumentException`).
  - A stored but unreadable string also falls back to the default (`AndroidPreference.kt:182-188`).
  - The enum constant names are therefore a persistence format and also a backup format.
- Store classes (`Preference.kt:25-49`):
  - app-state: key starts with `__APP_STATE_` (`Preference.appStateKey`). Never written to backups (`PreferenceBackupCreator.kt:62`).
  - private: key starts with `__PRIVATE_` (`Preference.privateKey`). Excluded from backups unless the user ticks the include-private option (`PreferenceBackupCreator.kt:82`).
  - normal: everything else. Always in backups.
- In every row below the Store column is one of: `normal`, `private`, `app-state`, or `n/a` (for the non-preference rows).

### 0.2 PROPOSAL: Rust settings store

- One `Settings` struct (serde, `#[serde(default)]` on every field so missing keys take the default) persisted as `~/.config/kurobayomi/settings.json` (`serde_json` is already a dependency in `/home/blackbox/kurobayomi/Cargo.toml`).
  - Write atomically: write to `settings.json.tmp`, then `rename`.
  - Change notification: a `tokio::sync::watch` channel per section. This replaces Aniyomi's `Preference.changes()` flows.
- Enum persistence: serde `#[serde(rename = "<Kotlin name>")]` on every variant, using the exact Kotlin constant names listed in the rows. Unknown string gives the default (use `#[serde(other)]` or a custom deserialiser). This keeps Aniyomi backup preference values importable.
- Secrets (private store) do not go into `settings.json`. They go to the freedesktop Secret Service (KWallet on KDE implements it) through the `oo7` crate.
  - Item attributes: `{app: "kurobayomi", kind: "tracker", tracker: "<id>", field: "<field>"}`.
- App-state keys live in the SQLite database or a separate `state.json`, never in `settings.json`, and are never exported.
- Field-name convention: `section.field_name`, snake_case. Colour ints are stored as `u32` `0xAARRGGBB`.
  - Aniyomi stores Android signed ARGB ints. `Color.White.toArgb()` is -1 (0xFFFFFFFF), `Color.Black.toArgb()` is -16777216 (0xFF000000), `Color.Transparent.toArgb()` is 0.
  - mpv receives them as `"#" + Int.toHexString().uppercase()`, which is `#AARRGGBB` (`SubtitleSettingsColorsCard.kt:156`).

## 10. Cross-checks and open decisions for the implementer

- Every row above points to a Kotlin definition read in full. The one structural oddity worth remembering: `pref_remember_volume` has a switch but no consumer.
- Three keys are saved as side effects and have no Settings row: `pref_player_aspect_state`, `pref_player_speed`, `pref_player_statistics_page`. The five `pref_player_filter_*` keys behave the same. Kurobayomi's settings screen should not add rows for these.
- P0 rows to implement first: `pref_reader_theme_key`, `pref_preserve_reading_position`, `pref_preserve_watching_position`, `pref_progress_preference`, `pref_library_columns_portrait_key`, `pref_library_columns_landscape_key`.
- Linux replacements named in this chunk:
  - `FLAG_KEEP_SCREEN_ON` becomes `gtk::Application::inhibit` (idle).
  - `MediaSession` becomes MPRIS2.
  - `WorkManager` periodic work becomes a tokio scheduler with an optional systemd user timer.
  - Cleartext `SharedPreferences` secrets become the Secret Service (`oo7`).
  - The internal `mpv.conf`/`input.conf` editors become real files in `~/.config/kurobayomi/mpv/`.
- Drops with a loss statement: `pref_pip_episode_toasts`, `pref_pip_on_exit` (no PiP; use the KDE "Keep above" window rule), `pref_remember_brightness` (no per-window backlight), `pref_mangasync_` (migration only), `pref_player_view_mode` (migration only).
