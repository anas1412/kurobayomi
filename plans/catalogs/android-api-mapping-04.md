If a glanceable surface is wanted later, a separate tiny KDE plasmoid reading the SQLite DB is the only route; that is out of scope for P0-P2 and recorded as a P3 drop in area:50-android-widgets.

### S5. Auto page background algorithm (`ImageUtil.chooseBackground`)

OBSERVED `core/common/src/main/java/tachiyomi/core/common/util/system/ImageUtil.kt:338-580`, called from `app/src/main/java/eu/kanade/tachiyomi/ui/reader/viewer/pager/PagerPageHolder.kt:154` when the page is not animated and `viewer.config.automaticBackground` is on. Input: decoded page (ARGB pixels), whether the window is landscape. Output: `Solid(color)` or a 4-stop vertical gradient. Rust signature proposal: `fn choose_background(img: &RgbaImage, landscape: bool) -> PageBackground` with `enum PageBackground { Solid(u32), Gradient([u32; 4]) }`.

Pixel predicates (`Int` ARGB, channels 0-255): `isDark = r < 40 && g < 40 && b < 40 && a > 200`; `isCloseTo(o) = |r-o.r| < 30 && |g-o.g| < 30 && |b-o.b| < 30`; `isWhite = r + g + b > 740`.

Algorithm, in order:

1. `white = 0xFFFFFFFF`. If decode fails, or `width < 50 || height < 50` → `Solid(white)`.
2. Constants: `top = 5`, `bot = height - 5`, `left = (width * 0.0275).toInt()`, `right = width - left`, `midX = width / 2`, `midY = height / 2`, `offsetX = (width * 0.01).toInt()`, `leftOffsetX = left - offsetX`, `rightOffsetX = right + offsetX`.
3. Sample pixels: `TL=(left,top)`, `TR=(right,top)`, `ML=(left,midY)`, `MR=(right,midY)`, `TC=(midX,top)`, `BL=(left,bot)`, `BC=(midX,bot)`, `BR=(right,bot)`. Dark flags for TL, TR, ML, MR, TC, BL, BR (not BC).
4. `darkBG = (TLdark && (BLdark || BRdark || TRdark || MLdark || TCdark)) || (TRdark && (BRdark || BLdark || MRdark || TCdark))`.
5. Ring `[TL, TC, TR, BR, BC, BL]`: for each index i compare with element `(i+1) % 6`; if for all six `!isWhite(c_i) && isCloseTo(c_i, c_{i+1})` → return `Solid(TL)`.
6. `whiteCorners` = count of white among TL, TR, BL, BR; if `> 2` then `darkBG = false`.
7. `blackColor` = first of: TL if TLdark, TR if TRdark, BL if BLdark, BR if BRdark, else `white`.
8. Counters `overallWhitePixels = overallBlackPixels = topBlackStreak = topWhiteStreak = botBlackStreak = botWhiteStreak = 0`. For `x` in `[left, right, leftOffsetX, rightOffsetX]` (label `outer`): locals `whitePixelsStreak, whitePixels, blackPixelsStreak, blackPixels = 0`, `blackStreak = whiteStreak = false`, `notOffset = (x == left || x == right)`. For `(index, y)` over `y in 0 until height step (height / 25)` (label `inner`): `pixel = img[x, y]`, `pixelOff = img[x + (x < width/2 ? -offsetX : +offsetX), y]`.
   - If `isWhite(pixel)`: `whitePixelsStreak++`, `whitePixels++`, if `notOffset` then `overallWhitePixels++`; if `whitePixelsStreak > 14` then `whiteStreak = true`; if `whitePixelsStreak > 6 && whitePixelsStreak >= index - 1` then `topWhiteStreak = whitePixelsStreak`. (Falls through to the shared tail below.)
   - Else: `whitePixelsStreak = 0`; if `isDark(pixel) && isDark(pixelOff)`: `blackPixels++`, if `notOffset` then `overallBlackPixels++`, `blackPixelsStreak++`, if `blackPixelsStreak >= 14` then `blackStreak = true`, then `continue inner` (skips the tail).
   - Shared tail: if `blackPixelsStreak > 6 && blackPixelsStreak >= index - 1` then `topBlackStreak = blackPixelsStreak`; `blackPixelsStreak = 0`.
   - After the inner loop: if `blackPixelsStreak > 6` then `botBlackStreak = blackPixelsStreak` else if `whitePixelsStreak > 6` then `botWhiteStreak = whitePixelsStreak`.
   - Then, first match wins: (a) `blackPixels > 22`: if `x == right || x == rightOffsetX` then `blackColor = TRdark ? TR : BRdark ? BR : blackColor`; `darkBG = true`; `overallWhitePixels = 0`; `break outer`. (b) `blackStreak`: `darkBG = true`; same right-side `blackColor` adjustment; if `blackPixels > 18` then `overallWhitePixels = 0` and `break outer`. (c) `whiteStreak || whitePixels > 22`: `darkBG = false`.
9. `topIsBlackStreak = topBlackStreak > topWhiteStreak`; `bottomIsBlackStreak = botBlackStreak > botWhiteStreak`. If `overallWhitePixels > 9 && overallWhitePixels > overallBlackPixels` then `darkBG = false`. If `topIsBlackStreak && bottomIsBlackStreak` then `darkBG = true`.
10. Landscape window: return `darkBG ? Solid(blackColor) : Solid(white)`.
11. Portrait: `botCornersIsWhite = isWhite(BL) && isWhite(BR)`, `topCornersIsWhite = isWhite(TL) && isWhite(TR)`, `topCornersIsDark = TLdark && TRdark`, `botCornersIsDark = BLdark && BRdark`, `topOffsetCornersIsDark = isDark(img[leftOffsetX, top]) && isDark(img[rightOffsetX, top])`, `botOffsetCornersIsDark = isDark(img[leftOffsetX, bot]) && isDark(img[rightOffsetX, bot])`. First match wins:
    - `darkBG && botCornersIsWhite` → `Gradient[black, black, white, white]`
    - `darkBG && topCornersIsWhite` → `Gradient[white, white, black, black]`
    - `darkBG` → `Solid(blackColor)`
    - `topIsBlackStreak || (topCornersIsDark && topOffsetCornersIsDark && (TCdark || overallBlackPixels > 9))` → `Gradient[black, black, white, white]`
    - `bottomIsBlackStreak || (botCornersIsDark && botOffsetCornersIsDark && (isDark(BC) || overallBlackPixels > 9))` → `Gradient[white, white, black, black]`
    - otherwise `Solid(white)`.
    (`black` here is `blackColor`.)

Rendering of the gradient: `GradientDrawable(Orientation.TOP_BOTTOM, intArrayOf(c0, c1, c2, c3))` distributes the four colors at evenly spaced positions 0, 1/3, 2/3, 1 (Android default when no offsets are given), so the first third is solid c0, the middle third blends c1 to c2, and the last third is solid c3. Proposal: GSK stops at offsets `0.0, 1/3, 2/3, 1.0`.
