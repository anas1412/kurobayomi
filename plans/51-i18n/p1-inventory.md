## Coverage of the scope

- Every scope file has at least one task (see column "Task ids").
- Every XML resource name is either ported into the generated `en.ftl` (T-51a-001) or handled by an explicit removal task (T-51a-018 for the 27 overridden core duplicates, T-51a-019 for the 133 names with no direct Kotlin reference). No name is left without a decision.
- The only translatable content in the scope that is not a name is the translation values in the locale directories (66 non-empty locales in each module; the Aniyomi module has one more directory, `ur`, which is empty). They are imported by T-51a-008 and checked by T-51a-009.
