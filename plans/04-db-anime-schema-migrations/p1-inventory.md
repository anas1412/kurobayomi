All paths are repo-relative to the Aniyomi clone `/home/blackbox/aniyomi-src`. Every file is SQLDelight input for the Kotlin class `tachiyomi.mi.data.AnimeDatabase` (package set in `data/build.gradle.kts`, database name `Database` for the manga one and `AnimeDatabase` for this one). Port decision vocabulary: Port (same behaviour, Rust code), Rewrite (same result, different mechanism), Replace-with-crate, Drop. Target modules refer to `p1-rust-design.md` section 1: crate `kuro-db`, subtree `kuro-db::anime`, SQL text under `crates/kuro-db/sql/anime/`. Companion documents: `p1-behavior.md`, `p1-data-and-config.md`, `p1-rust-design.md`, `p1-edge-cases-and-tests.md`, `p1-tasks.md`, and the topic files `p1-topic-fresh-vs-upgraded-schema.md`, `p1-topic-views-and-aggregates.md`, `p1-topic-triggers-and-versioning.md`, `p1-topic-legacy-migration-chain.md`, `p1-topic-reactive-queries.md`. There is no `p1-ui-parity.md`: no file in this scope renders UI.
