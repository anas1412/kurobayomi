By area: 37a 30 done, 6 partial. 38a 14 done, 3 partial. 38b 14 done, 7 partial.

What is solid: the pure library pipeline (`crates/kuro-domain/src/library`, `src/library/query.rs`, `t2/`), the library view and sheet, and the whole manga details engine (`src/entry_core`: flags, sort, view, selection, reducer, runner, store, banners). Almost every acceptance bullet has a test with the plan's own test names. The weak part is the wiring at the edges, which is what the user saw ("the redesign didn't reach everything", "global search has placeholders").

Main findings, all verified by following callers from `src/`:

1. **The library's "Search for ... globally" row opens a fake page** (T-37a-022). `library/mount.rs:168 open_global_search` calls `ui::open("global_search")` and then types the query into the first search entry it finds. It parks no route and no intent. `screens.rs:26` asks `browse::search_screen::body`, which returns `None` unless an intent, a parked route or an entry hand-off exists (`browse/search_screen.rs:372-385`). So it falls to `entry::global_search` (`entry.rs:657`): "Source A/B/C", a progress bar fixed at 0.6, `Title 1..8` cards and "No results found". The real page (`browse::search_screen`) is only reached when Browse, an entry page or a deep link parks a request first. Fix: in `open_global_search` call `crate::browse::pending::open(BrowseRoute::GlobalSearch { kind, source_id: None, query })` instead of `ui::open`. The same fallback is reachable from any other plain `ui::open("global_search")`.
2. **Library opens legacy pages for every non-local entry** (T-38a-001, T-37a-033). `library/mount.rs:329` calls `screens::open_entry(title, anime)`. For a non-local manga `local_flow::open::entry_for_title` returns false (it only finds local entries, `local_flow/open.rs:29`), so `screens.rs:91` pushes `entry::entry(title, ..)`, the pre-redesign page. A non-local anime goes the same way (`anime_id_for_title` also reads local rows only). The redesigned pages `entry_core::route::open(id)` and `entry_core::anime::route::open(id)` take an id and are already used by Browse, Updates, notifications and deep links, but not by the library for non-local entries. Fix: call them by id in `mount.rs nav().open`. The same title-based `open_entry`/`open_media` is still used by `updates/history_screen.rs:225,277`, `open_link.rs:39` (builds `title_n(id)`, a fake "Title N") and `live.rs` (other shards).
3. **The Continue button opens a fake player for non-local anime** (T-37a-033). `mount.rs:345` calls `screens::open_media`, which for a non-local anime pushes `player::player(title, unit)`, a placeholder surface (`player.rs:65`, "placeholder surface", duration 1420 s). `deps().always_external` is `|| false` (`mount.rs:446`) so `pref_always_use_external_player` is never read, and `Nav::resume` ignores `Resume.external`. `item_downloaded` is `|_| false` (`mount.rs:447`), so with downloaded-only on, every entry's next item is filtered out and the toast "Next chapter not found" shows.
4. **Download wiring is absent in the manga details page and the library**. `entry_core::backend::SourceBackend` (the backend the app uses, `route.rs:152`) implements only `has_logged_in_tracker`, `source_info`, `fetch_details` and `fetch_chapters` (`backend.rs:166-205`). Every other `Backend` method keeps its default: `downloads()` is empty, `enqueue_downloads()` is false, `cancel_download`, `delete_downloads`, `bind_enhanced`, `remove_cover` do nothing, and `is_http_source()` is false, so the WebView button and the Share overflow item never show. `bar_state(.., configurable_source = false)` (`route.rs:819,1115`) hides the source Settings item. `Page::apply_download` (`page.rs:235`) is called only by tests, so no download event reaches the list. In the library, `mount::on_download` and `mount::on_delete_downloads` are never called by anything, so the selection Download action and "delete downloads" only log.
5. **The details page's Tracking button opens a mock sheet**: `ui::open("tracking_sheet")` (`route.rs:689,1155`) builds `entry::tracking()` (`entry.rs:723`), fixed rows "AniList bound, MyAnimeList, Kitsu". `entry_core/tracking/*` has logic but no widget.
6. **Small ones**: `from_source` is hard-coded false in the real page (`route.rs:151`), so the description never starts expanded. The saved library tab is written (`view/mod.rs:881`) but never read back. The "Use -term to exclude" search hint does not exist. The Settings switch "Per-category settings for sort" resets only manga categories when turned off (`settings_ui/library.rs:42`), though the preference is shared, so anime categories keep their own sorts. `SourceBackend::fetch_chapters` always passes `manual: true`. No code registers the local source in the source directory (rg of `browse/builtin.rs`, `browse/mount.rs`, `ext_host.rs` found nothing), so a manual refresh of a local manga most likely reports "source not installed" (not run, so not confirmed).
