# P0 audit 05: areas 19a, 20a, 23a, 25a

Read-only audit by reading code. Cargo was not run; every "test exists" means the test name was found in the source, not that it passes. A task is DONE only if the code path is reachable from the app window (`src/main.rs` -> `ext_host::start`, `browse::mount`, the reader, the entry pages).

## Summary

57 P0 tasks: DONE 21, LIB_ONLY 22, PARTIAL 14, MISSING 0, NOT_APPLICABLE 0.

What matters most:

1. **Extension install is a stub in the window.** `src/browse/mount.rs:197` `HostBackend::install` just reports `InstallStep::Error`; `uninstall` and `refresh` do nothing. `AnimeExtensions::install`, `InstallTracker::begin`, `verify_download`, `place` and `download` have no caller in `src/`. T-19a-011, -031, -032, -033 are LIB_ONLY for that reason. Listing, scanning, trust and reconciliation do run (`ext_host::start`).
2. **No installed extension can run.** `src/browse/anime/directory.rs` says "the app has no anime source registry yet". `kuro-source-wasm` is never referenced from `src/`. The manga scan is called with an empty digest map (`src/ext_host.rs:284`), so every manga package is Untrusted and nothing is instantiated. Only the built-in Rust sources and recipe sources work.
3. **The whole manga download engine is LIB_ONLY.** `DownloadManager`, queue, scheduler, pipeline, store, notifier and restore are never created in `src/`. `src/updates/download_host.rs` default backend answers "nothing can be queued or deleted". Anime `install_queue` is also never called.
4. **The download index never scans in the app.** `DownloadIndex::open` is called in `src/shell/host.rs:39`, but `renew_if_stale` has no caller, so the tree stays empty unless a snapshot file exists.
5. **Library update and backup check use `NothingInstalled`** (`src/misc/runner.rs:71`, `src/backup_run.rs:42`, `src/pref_model/backup_pages.rs:301`). The restore check lists every source as missing, including the built-in ones.
