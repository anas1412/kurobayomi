By area: 43a 47 done, 1 lib-only, 7 partial. 43b 26 done, 1 lib-only, 4 partial.

The reader is the most complete area audited so far. `crate::reader::launch::open_chapter` is the real entry (called from `src/entry_core/route.rs:706`, `src/misc/notify.rs:323`, `src/shell/deep_link_page.rs:237`, `src/local_flow/reader.rs`), it builds a `ReaderCore` and attaches the area 44 viewers (`screen::install_viewer`), the chrome, the sheets, the progress writer and the live settings feed. The placeholder reader (`player::reader`) is gone.

Main findings:

1. **Chapter reference counting is never driven** (T-43a-002). `ReaderChapter::add_ref/release` and `ViewerChapters::replace/add_refs/release_all` (`src/reader/model.rs:219-240,369-386`) are called only by tests. The app recycles a loader through `Drop` instead.
2. **Online reading works only for the built-in sources** (T-43a-007, T-43a-023). `source_pages::online` (`src/reader/source_pages.rs:281`) asks `directory::current().manga_source(id)`; only `browse/builtin.rs:150` implements `manga_source`, so any installed or wasm source ends in "Source not found". `SourceKind::Stub` (the "Source not installed" message) is never built outside tests. Reader opening also uses an always-open gate (`launch::open_gate`), so it does not wait for the source manager.
3. **The data saver never applies in the app** (T-43a-014). `HttpPageSource::data_saver` defaults to `None` (`src/reader/loader/http.rs:48`) and `source_pages.rs` does not override it; the Settings data-saver page has no effect on the reader.
4. **Overflow "Open in WebView" is the browser, and relative chapter urls fail** (T-43a-040). `chrome::web_url` returns a url only for an absolute http(s) chapter url (`src/reader/chrome.rs:34`); source chapter urls are usually relative, so Open in browser, Open in WebView and Share all show "Unknown error". No WebView window exists (recorded in `src/reader/mod.rs`, G-35).
5. **Dead state helpers for the load visuals** (T-43a-076): `state::page_area_spinner`, `state::load_view`, `UiState::begin_adjacent_load` have no caller in `src/`. The initial spinner and the navigator spinner work; the page-area spinner for a background load does not exist (only the transition card status line shows a spinner for the destination chapter).
6. **`ReaderSettingsModel` has no caller** (T-43b-030). The settings window talks to `ReaderCore` through `MangaChoices` instead.
7. **Long press is not suppressed during a zoom animation** (T-43b-013, D-10). `PageView::long_timer` (`src/reader/page_view.rs:653`) checks only the generation and the preference; `zoom_locked` there means "zoom disabled", not "animating".
8. **Duplicates, not gaps**: `viewers::gap::calculate_chapter_gap` has no caller (the transition card uses `kuro_domain::items::missing::item_gap`, same rule, tested there); the option lists `TAP_ZONES`, `IMAGE_SCALE_TYPE`, `ZOOM_START`, `COLOR_FILTER_MODE`, `ColorFilterBlend`, `ReadingMode::viewer_type` and `pref_rules::{reading_direction, tapping_label_key}` are tested but the app uses its own tables (`settings_window` chips, `blend_box::blend_mode`, `viewers::ViewerKind`). Two sources of truth for the same values.
9. **Stale placeholder remnants**: `src/screens.rs:40` still maps screen id `reader` to `page_for("Title 1", "Chapter 1")`, and `spec/reader_player.json` still holds the old mockup `reader` screen (fixed 20-page slider). Nothing I found pushes the id `reader`, so it is not reachable from a normal flow, but the literal is G-03 left in code.
10. **Test-only gaps**: the SQL mask merge `set_viewer_bits` has no test against a real database (the session tests use a recorder), reader enum round-trip is tested for two values, and `going_to_downloaded` (local shortcut, off-thread lookup) has no test.

Rules applied: a task whose only unmet bullet is an implementation choice recorded in code or in another plan area (the preference store is the TOML store of area 02, not a SQLite `kv` table; `Epub` is a mode of the Archive loader; reader prefs do not go through the writer actor) is DONE with the deviation named.
